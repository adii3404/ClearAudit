WHAT IS CLEARAUDIT?
--------------------------------------------------------------------------------
ClearAudit is a lightweight corporate expense reimbursement platform designed
for mid-size to enterprise organizations operating in India. It replaces
paper-based claim workflows with a fully digital, browser-native experience.

Employees photograph or upload receipts, fill in transaction metadata, and
receive a unique audit tracking token. Administrators review queued claims
through a dashboard with real-time metric counters and take action — accept,
reject, or revoke with mandatory compliance notes.

TECHNICAL ARCHITECTURE
--------------------------------------------------------------------------------
Frontend Layer:
  - React 19.0.1 with functional components and hooks throughout.
  - React Router v7 for client-side routing across /login, /employee, /admin.
  - Motion (Framer Motion successor) for subtle UI transitions.

Styling Layer:
  - Tailwind CSS v4 via the @tailwindcss/vite plugin (zero PostCSS config).
  - Monochrome design tokens: grayscale palette, sharp borders, minimal shadows.
  - Lucide React icon set for consistent, lightweight iconography.

Build & Tooling:
  - Vite 8 with ESM-first module resolution and native HMR.
  - TypeScript 7 with strict mode enabled (tsc --noEmit for lint checks).
  - No runtime backend — all state persisted in browser localStorage.

Data Persistence:
  - User credentials, claim records, and audit history stored in localStorage.
  - Deterministic token generation: format CA-XXXX-XXXX (alphanumeric).
  - CSV export for offline ERP synchronization and compliance reporting.

CLAIM STATE MACHINE
--------------------------------------------------------------------------------
Every submitted claim follows this deterministic lifecycle:

  DRAFT --> SUBMITTED --> PENDING --> ACCEPTED (Disbursed)
                                  |-> REJECTED (Denied)
                                  |-> REVOKED  (Returned with reason)
                                        |-> Re-submission allowed

State transitions are logged with timestamps and actor identity for full
audit traceability. Revocations require a mandatory free-text remediation
note from the administrator before the state change is committed.

GST VOUCHER GENERATION
--------------------------------------------------------------------------------
ClearAudit generates authentic Indian corporate GST reimbursement vouchers:
  - Tax breakdown: CGST (9%) + SGST (9%) for intra-state, IGST (18%) for inter-state.
  - Voucher rendered via HTML5 Canvas with high-fidelity layout.
  - Export options: downloadable PNG, browser print dialog.
  - Each voucher is linked to its parent claim via the audit token.
