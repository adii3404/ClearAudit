INTRODUCTION
--------------------------------------------------------------------------------
ClearAudit is an enterprise-grade, browser-native expense reimbursement and
audit compliance platform purpose-built for Indian corporate environments.

It provides two distinct portals:
  1. EMPLOYEE PORTAL — Submit, track, and manage expense claims.
  2. ADMIN PORTAL   — Review, action, and export the complete audit queue.

No server infrastructure is needed. The entire application runs client-side
with React 19, Vite 8, and Tailwind CSS v4, persisting all data in the
browser's localStorage.

EMPLOYEE WORKFLOW
--------------------------------------------------------------------------------
1. Login at /login with role toggle (Employee / Admin).
2. Navigate the left sidebar: Open Camera, Upload from Local, Ask Query,
   Expense Policy, Change Password.
3. Capture a receipt via the live webcam scanner (with viewport guides) or
   drag-and-drop a file (.jpg, .png, .pdf — max 5MB).
4. Fill in metadata: Description, Transaction Date, Category, Amount (INR).
5. Submit and receive a unique audit token (format: CA-XXXX-XXXX).
6. Track claim status in Recent Submissions: Pending, Approved, Revoked, Rejected.
7. Download GST-compliant voucher slips as PNG or print directly.
8. Use the Ally AI chatbot for on-demand expense policy guidance.

ADMIN WORKFLOW
--------------------------------------------------------------------------------
1. Login at /login as Admin.
2. View real-time metric counters:
   - Pending Claims (INR total)
   - Accepted & Disbursed (INR total)
   - Revoked Claims (count)
   - Total Queue Records
3. Filter claims by status: All, Pending, Accepted, Rejected, Revoked.
4. Search claims by keyword across all fields.
5. Take action on each claim:
   - ACCEPT  — Authorize for disbursement.
   - REJECT  — Mark as non-reimbursable.
   - REVOKE  — Return with mandatory compliance note/tip.
   - INSPECT — View and export the official GST voucher slip.
6. Generate a comprehensive CSV report of the full audit queue.

SETUP & COMMANDS
--------------------------------------------------------------------------------
Prerequisites: Node.js v18+ and npm.

  # Clone the repository
  $ git clone https://github.com/adii3404/ClearAudit.git
  $ cd ClearAudit

  # Install dependencies (legacy peer deps needed for esbuild/vite compat)
  $ npm install --legacy-peer-deps

  # Start the development server on port 3000
  $ npm run dev

  # Type-check the codebase
  $ npm run lint

  # Build for production
  $ npm run build
