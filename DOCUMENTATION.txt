DOCUMENTATION & ARCHITECTURAL SPECIFICATIONS

1. PROJECT OVERVIEW & CORE MISSION
--------------------------------------------------------------------------------
ClearAudit is an enterprise-grade corporate expense reimbursement and auditing
management platform designed for streamlined business-to-business (B2B) workflows.

Key Objectives:
- Minimalist, monochrome, distraction-free corporate user interface.
- Complete auditability for claims submission, verification, and disbursement.
- Built-in compliance assistant ("Ally AI") to interpret travel and expense policies.
- Support for Indian GST-compliant vouchers and official tax invoice generation.
- Zero server backend requirement for base evaluation: persistent local state
  leveraging browser localStorage with deterministic data hydration.


2. ROLE-BASED ACCESS CONTROL & AUTHENTICATION
--------------------------------------------------------------------------------
ClearAudit implements a dual-persona authentication matrix:

A. Employee Role:
   - Default Identity: employee@clearaudit.internal
   - Access Permissions:
     * Document capture via camera or direct local upload (.jpg, .png, .pdf up to 5MB).
     * Claim metadata submission (Category, Amount in INR, Transaction Date).
     * Ally AI contextual policy chat assistance.
     * Status tracking of submitted reimbursement claims.
     * Receipt token lookup and voucher slip generation.

B. Administrator / Auditor Role:
   - Default Identity: admin@clearaudit.internal
   - Access Permissions:
     * Complete operational visibility across company expense pipeline.
     * Metric counters: Pending Claims (INR), Accepted & Disbursed (INR), Revoked Claims.
     * Claim actions: Accept, Reject, Revoke (with mandatory remediation notes).
     * Full audit trail inspection and master CSV export.


3. REIMBURSEMENT WORKFLOW & AUDIT LIFECYCLE
--------------------------------------------------------------------------------
The claim lifecycle transitions through strict sequential states:

[Draft / File Ingestion]
         │
         ▼
[Claim Submission] ──> Unique Token Minting (e.g., CA-B3CU-HAXA)
         │
         ▼
    [Pending] ─────────────── Auditor Review Queue
         │
         ├───> [Accepted] ──> Disbursed / Voucher Finalized
         ├───> [Rejected] ──> Denied / Non-reimbursable
         └───> [Revoked]  ──> Returned with Mandatory Auditor Tip/Reason
                                     │
                                     └───> Re-submission Allowed

Key Features:
- Indian GST Invoice & Voucher rendering with authentic tax breakup (CGST/SGST/IGST).
- Downloadable PNG vouchers with high-fidelity canvas generation.
- Full CSV export capability containing claim ID, employee ID, date, category,
  amount, status, and remarks for ERP synchronization.


4. TECHNICAL STACK & RUNTIME CONFIGURATION
--------------------------------------------------------------------------------
Architecture Specifications:
- UI Runtime: React 19 (19.0.1) & React Router v7
- Build Tool: Vite 8 with ESM bundle optimization
- Typography & Styling: Tailwind CSS v4 with custom monochrome styling tokens
- Iconography: Lucide React
- Animation Engine: Motion (formerly Framer Motion)

Development & Production Commands:
- Install Dependencies:
  $ npm install --legacy-peer-deps
- Run Local Dev Server:
  $ npm run dev -- --port=3000 --host=0.0.0.0
- Run TypeScript Verification:
  $ npm run lint
- Build Production Distribution:
  $ npm run build
